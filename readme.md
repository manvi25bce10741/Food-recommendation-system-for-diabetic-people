# DiaPlate

DiaPlate is a meal-based recommendation system focused on helping people with diabetes plan their meals.

It suggests meals according to a user's profile and meal preferences.

## Features

- Age-based meal recommendations
- Dietary preference selection
- Meal-based filtering
- Diabetes-type-based scoring
- Glycemic Index consideration
- Fibre-based scoring
- Micronutrient consideration
- Nutrition information
- Vegetarian and non-vegetarian options
- Responsive user interface

## User Inputs

The user provides:

- Age
- Gender
- Dietary preference
- Meal
- Type of diabetes

## How It Works

The application filters the food database and calculates a score for each suitable dish.

The scoring system considers:

- Diabetes-type compatibility
- Glycemic Index
- Fibre content
- Age-group compatibility
- Relevant micronutrients
- Sugar
- Sodium

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Running the Project

No build tools or npm packages are required.

### Option 1: Open Directly

Open `index.html` in a web browser.

### Option 2: Using VS Code

Use a local development server, such as **Live Server**, in VS Code.

## Disclaimer

DiaPlate is an educational demonstration and is not intended to provide medical advice.

Nutrition values are estimates, and users should consult qualified healthcare professionals for personalized dietary guidance.
