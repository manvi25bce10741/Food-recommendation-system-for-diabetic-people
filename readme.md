#DiaPlate
DiaPlate is a meal based recommendation system solely focused on helping diabetic people plan their meals.It suggests meals according to a user's profile and meal preferences.
FEATURES:
-age based meal recommendations
-dietary preference selection
-meal-based filtering
-diabetes-type based scoring
-glycemic Index consideration
-fibre-based scoring
-micronutrient consideration
-nutrition information
-vegetarian and non-vegetarian options
-responsive user interface

The user provides:
-Age
-Gender
-Dietary preference
-Meal
-Type of diabetes

The application filters the food database and calculates a score for each
suitable dish.

The scoring system considers:
Diabetes-type compatibility
Glycemic Index
Fibre content
Age-group compatibility
Relevant micronutrients
Sugar
Sodium

- HTML5
- CSS3
- JavaScript
- Google Fonts

Running the Project
No build tools or npm packages are required.
Open `index.html` in a browser, or use VS Code with a local server such
as Live Server.

Disclaimer
DiaPlate is an educational demonstration and is not intended to provide
medical advice. Nutrition values are estimates and users should consult
qualified healthcare professionals for personalized dietary guidance.
